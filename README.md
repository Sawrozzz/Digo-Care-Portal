# 🚀 React + Vite + TypeScript + Tailwind CSS Starter

This project is built using **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.  
It provides a fast, modern, and scalable frontend setup with strong typing and utility-first styling.

---

## 📦 Tech Stack

- ⚛️ React (UI Library)
- ⚡ Vite (Next-generation frontend tooling)
- 🟦 TypeScript (Static typing for JavaScript)
- 🎨 Tailwind CSS (Utility-first CSS framework)
- 📦 Node.js version >= 22.x

---

- 📦 Run the project `npm run dev`
